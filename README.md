# Old Things Collector / 旧物回收员

A short point-and-click mystery created for Ludum Dare 60, with the theme **Old Tech**.

You run an old-goods shop and can hear objects that carry a powerful attachment. A letter from a deceased man's younger brother brings you to a room full of old belongings. The objects cannot hear one another; you must connect their memories yourself.

## Download and play

Download **OldThingsCollector_EN_Jam_v1.zip** from this repository's Releases page.
Extract the entire archive, then run **RoomNavigation.exe**. Keep all included files and folders together. Unity is not required.

- Platform: Windows 10 / 11, 64-bit
- Language: English
- Controls: mouse; operate the flip phone using its physical keys
- No save system: quitting resets progress

This is a short Jam chapter ending with the final apology email. The wider investigation remains open.
